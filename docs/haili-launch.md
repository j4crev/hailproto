# Haili provider reference

Haili runs the reference provider and browser client. Configuration, incident
ownership, backups, restoration and application rollback are documented in
[Haili operations](haili-operations.md). Inspect the running deployment before
relying on a particular release or feature gate.

For a new independent deployment, follow the [provider setup guide](../apps/server/deploy/public/README.md)
and [first administrator walkthrough](provider-admin-setup.md).
Connection messaging and supported history transfers are described in
[connection messaging](connection-messaging.md) and [custody transitions](../apps/cli/docs/custody-transitions.md).
